# Публикация «ЕГЭ-Навигатора» на GitHub Pages и в Google

Пошаговая инструкция. Ничего устанавливать не нужно — всё делается в браузере.
Занимает 5–7 минут. Бесплатно: GitHub Pages работает для публичных репозиториев.

---

## Шаг 0. Что заменить ДО публикации

1. **Ссылка на анкету.** В `index.html` найдите `https://forms.gle/your-form-id`
   (блок «Анкета», рядом комментарий `ЗАМЕНИ`) и вставьте ссылку на свою Google Форму.
   Если формы ещё нет — создайте её на [forms.google.com](https://forms.google.com),
   потом нажмите «Отправить» → вкладка «Ссылка» → скопируйте.
2. **Цифры графиков.** `assets/chart-data.js`, блок с комментарием «ЗАМЕНИ на свои».

Если оставить заглушки, сайт опубликуется, но кнопка анкеты будет вести в никуда.

---

## Шаг 1. Аккаунт GitHub

Есть аккаунт — пропустите. Нет — [github.com/signup](https://github.com/signup):
почта, пароль, имя пользователя (латиницей, это попадёт в адрес сайта).

**Обязательно подтвердите e-mail** из письма GitHub — без подтверждения Pages не включится.

Запомните имя пользователя: дальше оно обозначено как `ЛОГИН`.

---

## Шаг 2. Создать репозиторий

1. Откройте [github.com/new](https://github.com/new).
2. **Repository name:** `ege-navigator`
3. **Description:** `Сайт-навигатор по подготовке к ЕГЭ`
4. Выберите **Public** (приватный не подойдёт для бесплатного Pages).
5. Галочку «Add a README file» **не** ставьте — README у нас уже есть.
6. **Create repository**.

---

## Шаг 3. Загрузить файлы

В пустом репозитории нажмите **uploading an existing file**
(или **Add file → Upload files**).

Перетащите в окно **всё содержимое папки** `default-workspace`:

```
index.html
README.md
PUBLISH.md
.nojekyll
assets/          ← папка целиком, вместе с vendor
```

Важно: перетаскивайте **папку `assets`**, а не только файлы из неё — структура
`assets/vendor/chart.umd.min.js` должна сохраниться, иначе графики не загрузятся.

Внизу нажмите **Commit changes** (сообщение можно оставить по умолчанию).
Если браузер не даёт перетащить папку — загрузите файлы по очереди через
**Add file → Upload files**, а папку `assets` создайте так: **Add file → Create new file**,
в поле имени напишите `assets/vendor/.gitkeep`, затем загрузите `chart.umd.min.js` внутрь `assets/vendor`.

---

## Шаг 4. Включить GitHub Pages

1. В репозитории: **Settings** (сверху) → в левом меню **Pages**.
2. **Build and deployment → Source:** `Deploy from a branch`.
3. **Branch:** `main`, папка `/ (root)` → **Save**.
4. Подождите 1–2 минуты и обновите страницу. Сверху появится:

   > Your site is live at `https://ЛОГИН.github.io/ege-navigator/`

Это и есть адрес сайта. Откройте его — должна открыться главная страница.

---

## Шаг 5. Проверить, что всё работает

- Открывается с телефона, меню-бургер работает.
- Графики нарисовались (4 штуки).
- Кнопка «Пройти анкету» ведёт на вашу форму.
- Ссылки на ФИПИ, Решу ЕГЭ и остальные открываются в новой вкладке.

Если графиков нет — почти всегда потерялась папка `assets/vendor`.

---

## Шаг 6. Google: чтобы сайт нашёлся в поиске

Публикация на GitHub **не** отправляет сайт в Google автоматически. Нужно один раз
подтвердить права на сайт в Google Search Console.

1. Откройте [search.google.com/search-console](https://search.google.com/search-console)
   и войдите тем же Google-аккаунтом.
2. **Добавить ресурс** → выберите **«Префикс URL»** (справа).
3. Вставьте адрес **с косой чертой на конце**: `https://ЛОГИН.github.io/ege-navigator/`
4. В окне подтверждения выберите способ **«HTML-файл»** и скачайте файл
   вида `google1a2b3c4d5e6f.html`.
5. Загрузите этот файл в **корень** репозитория (Add file → Upload files), Commit changes.
6. Подождите минуту, вернитесь в Search Console и нажмите **«Проверить»**.
   Должно появиться «Владение подтверждено».
7. Слева: **Индексирование → Инспекция URL** → вставьте адрес сайта → **Enter** →
   **«Запросить индексирование»**.

Дальше Google сам решит, когда показать сайт: обычно от 2 дней до 2 недель.
Проверить можно запросом в Google: `site:ЛОГИН.github.io/ege-navigator`.

После подтверждения владения пришлите мне адрес сайта — я доделаю техническую часть
для поиска: `sitemap.xml`, `robots.txt`, канонический адрес и превью для соцсетей
(это ещё 3 файла на загрузку).

## Если что-то пошло не так

| Симптом | Причина и решение |
|---|---|
| 404 на `ЛОГИН.github.io/ege-navigator/` | Pages ещё собирается (до 2 минут) или выбран не тот branch/папка в Settings → Pages |
| Открывается список файлов вместо сайта | `index.html` лежит не в корне, а внутри папки — перенесите в корень |
| Нет стилей, «голый» текст | Не загрузилась папка `assets` — проверьте, что путь `assets/styles.css` существует |
| Страница есть, но не находится в Google | Не выполнен шаг 6 либо прошло меньше 2 дней |
| Pages не включается | Не подтверждён e-mail или репозиторий приватный |

---

## Обновить сайт потом

Откройте нужный файл в репозитории → значок карандаша (**Edit**) → правки →
**Commit changes**. Через минуту изменения появятся на сайте.

---

## Приятный бонус: короткая ссылка

Адрес `ЛОГИН.github.io/ege-navigator` длинный. Можно сделать репозиторий
`ЛОГИН.github.io` — тогда сайт откроется по адресу `https://ЛОГИН.github.io`,
но в аккаунте может быть только один такой репозиторий.
