# ЕГЭ-Навигатор

Одностраничный сайт-навигатор по подготовке к ЕГЭ: официальные ресурсы, сравнение платформ,
недельный план и результаты анкеты.

## Как открыть

Двойной клик по `index.html` — сайт работает локально, без интернета и сервера.
Графики отрисовывает Chart.js, он лежит рядом в `assets/vendor/`, поэтому CDN не нужен.

```
index.html            — вся страница и тексты
assets/styles.css     — оформление и адаптивность
assets/app.js         — меню, чек-лист, графики
assets/chart-data.js  — цифры для графиков  ← менять здесь
assets/vendor/        — Chart.js 4.4.9
```

## Что заменить перед публикацией

1. **Ссылка на анкету.** В `index.html` найдите `https://forms.gle/your-form-id`
   (блок «Анкета», рядом есть комментарий `ЗАМЕНИ`) и вставьте ссылку на свою Google Форму.

2. **Данные графиков.** Откройте `assets/chart-data.js` — там один объект с подписями
   и числами, блок помечен комментарием «ЗАМЕНИ на свои». Подписи и значения должны быть
   одинаковой длины; для процентных диаграмм сумма должна равняться 100.

3. **Число опрошенных.** В том же файле `meta.sampleSize` — оно выводится в центре
   кольцевой диаграммы и в подписи блока.

4. **Цены в таблице сравнения** — ориентировочные, проверьте актуальные на сайтах школ.

## Как проверить

- Открыть `index.html`, прокрутить: меню подсвечивает текущий блок, таблица сравнения
  прокручивается вбок на телефоне, чек-лист сохраняет отметки после перезагрузки.
- Ширины 1440, 820 и 390 px проверены в Edge: горизонтальной прокрутки страницы нет.

## Публикация

Сайт статический — подойдёт GitHub Pages, Netlify или любой хостинг.
Достаточно загрузить `index.html` и папку `assets` целиком.

## Доступность и принципы

- Палитра: `#1e3a8a`, `#3b82f6`, `#16a34a`, белый фон; шрифт Segoe UI / Inter.
- Все внешние ссылки открываются в новой вкладке (`target="_blank" rel="noopener noreferrer"`).
- Есть пропуск к содержимому, `aria`-подписи у графиков и таблиц, поддержка
  `prefers-reduced-motion`.
- Никакой рекламы, стоковых фото людей и тёмной темы.
